# X01 rules (501 / 301)

Status: v1. This document is the source of truth for the :game-engine X01 tests.
Rule ids (C1, D1, ...) are stable and referenced by tests.

## Configuration

- C1. Start score is 501 or 301. Default: 501.
- C2. Checkout rule is DOUBLE_OUT or SINGLE_OUT. Default: DOUBLE_OUT.
- C3. Entry is free (straight in): every dart scores from the first one.
- C4. 1 to 4 players, in a given order. Names are trimmed, must be non-blank, at most
  20 characters, and unique ignoring case. The engine receives the final order;
  shuffling is the caller's responsibility.
- C5. An invalid configuration is rejected with an explicit error.

## Darts

- D1. A dart is exactly one of: single, double or triple of 1 to 20; outer bull (25);
  bull (50); miss (0).
- D2. Triple bull and double outer bull do not exist and cannot be created.
- D3. Bull (50) counts as a double for checkout.

## Turns

- T1. Players throw in configuration order; the first player starts. A turn has at
  most 3 darts.
- T2. A turn ends after its third dart, on a bust, or on a checkout. Play then passes
  to the next player, wrapping around after the last one.

## Scoring, bust and checkout

- S1. Each dart subtracts its value from the current player's remaining score.
  Let n be the remaining score after the dart.
- S2. DOUBLE_OUT: the dart is a bust if n < 0, or n == 1, or n == 0 and the dart is
  not a double (bull counts as a double). n == 0 with a double is a checkout.
- S3. SINGLE_OUT: the dart is a bust if n < 0. n == 0 is a checkout with any dart.
- S4. On a bust, the dart is recorded, the player's remaining score is restored to
  its value at the start of the turn, and the turn ends immediately.
- S5. On a checkout, the player wins and the leg is finished. Any further dart is
  rejected with an explicit error.

## Undo

- U1. Undo removes the last recorded dart, whatever the player or turn, including
  bust darts and the winning dart. The resulting state is exactly the state before
  that dart was recorded.
- U2. Undo can be repeated down to an empty game. Undo on an empty game has no
  effect, and the engine exposes whether undo is possible.
- U3. Undoing the winning dart reopens the leg.

## End of leg and ranking

- E1. The winner is ranked first. Other players are ranked by remaining score,
  ascending.
- E2. Players with equal remaining scores share the same rank, and the next rank is
  skipped (1, 2, 2, 4).

## Statistics

- A1. Three-dart average per player = points scored / darts thrown x 3, where points
  scored = start score - current remaining score. Bust darts count as thrown. A
  player with no dart thrown has no average (absent, not zero).
- A2. The engine exposes, per player: remaining score, darts thrown, three-dart
  average, and the darts of the current turn.

## Persistence contract

- P1. A game is fully defined by its configuration and its ordered list of darts.
  The state is derived by replaying the darts from the configuration; the same
  input always yields the same state.

## Planned extensions (not in v1; the design must not prevent them)

- Continue playing for places after the first checkout.
- Legs and sets, with the starting player alternating between legs.
- Double-in entry rule.
- Checkout suggestions.
- Game history, statistics and heatmaps. Every dart keeps its segment and multiplier;
  a dart may later carry an optional board position (from a touch board or the
  camera) without breaking existing data.
